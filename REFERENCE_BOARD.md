# V8 Motion Lab — Reference Board

## Primary direction
This project is anchored to a **modern high-performance V8** visual language, not a classic carbureted muscle V8.

## Core reference pillars

### 1. Chevrolet LT6
Why it matters:
- modern flat-plane V8 character
- high-rev mechanical drama
- useful benchmark for aggressive performance engine personality

Links:
- https://media.chevrolet.com/media/us/en/chevrolet/home.detail.html/content/Pages/news/us/en/2021/oct/1026-corvette-z06.html

### 2. Ford 5.0 Coyote
Why it matters:
- modern production V8 proportions
- strong reference for upper engine packaging and head/cover massing
- balances realism against over-stylized race-only geometry

Links:
- https://performanceparts.ford.com/download/instructionsheets/COYOTE_TECH_GUIDE_062819.PDF
- https://www.ford.co.uk/content/dam/guxeu/uk/documents/home/experience-ford/news/component-sales/5-0l-32v-tivct-mustang-coyote-service-engine.pdf

### 3. Ferrari V8 family
Why it matters:
- premium presentation cues
- sculptural upper massing
- high-performance engine as an object of industrial design

Links:
- https://www.ferrari.com/
- https://www.ferrari.com/content/dam/ferrari-fcom/old/pdf/cs_reveal_ferrari_f8_tributo_gbr.pdf

## Rules for future passes
- preserve single-file output
- improve silhouette toward a modern DOHC performance V8
- improve cutaway readability without destroying the exterior form
- strengthen high-RPM drama while keeping the engine readable on mobile
