# 건물 번호와 목록 (ADR-0030)

모든 건물에는 고유번호(uid)가 있다. 버그 보고, 건물별 수정, 기준 장면, 저장 키를 말할 때 이 번호를 쓴다. 같은 소스로 빌드하면 언제나 같은 번호가 나온다.

## 번호 규칙 (`src/buildingid.js`)
| 종류 | 형식 | 예 | 뜻 |
|---|---|---|---|
| NEON 블록 건물 | `NC-B{열}_{행}-{k}` | `NC-B04_06-2` | 외곽 링을 포함한 블록 격자(00~10)의 그 블록에서 k번째로 만든 건물 |
| NEON 외곽 모델 타워 | `NC-R{N/S/E/W}{k}` | `NC-RN03` | 산책로를 따라 선 모델 타워, 변마다 순서 |
| NEON 원경 탑 | `NC-F{k}` | `NC-F017` | 도시 밖 원경 탑 |
| 스카이타워 | 원래 블록 번호 + 별칭 `NC-SKY` | | 1000 m 타워 |
| 다른 도시 건물 | `{도시}-{i}` | `HARBOR-0123` | `citylayout.js` 배치의 i번째 건물 |
| 다른 도시 랜드마크 | `{도시}-L{i}` | `MID2-L1` | 랜드마크 타워 |
| 마을 건물 | `{마을}-{i}` / `-TOW` / `-CAN` | `V12-004` | 마을 계획의 i번째 건물, 급수탑, 주유소 지붕 |
| 농장 | `{농장}-H` / `-B` | `F3-H` | 농가, 헛간 |
| 산업·통신 | `{시설 id}` | `W0`, `T5` | 풍력·태양광·광산·정유 단지, 통신탑 |
| 휴게소 | `SA-{도로}-{표본}` | `SA-HW3-400` | 고속도로 휴게소 |

번호는 생성기의 순서를 따른다. 생성기(배치 규칙, 난수 순서)를 바꾸는 PR은 `--check`로 바뀐 번호를 확인하고 본문에 적는다.

## 쓰는 법
- 목록: `registry.csv`(uid, 지역, 종류, 중심 x·z, 폭·깊이·높이, 층수 추정, 이름, 입장 가능, 출처 파일).
- 다시 만들기: `node build/build.mjs && node tests/tools/building-registry.cjs`
- 바뀐 점 확인: `node tests/tools/building-registry.cjs --check`(추가·삭제·이동)
- 게임 안:
  - 휴대폰 → 설정 → "건물 번호 표시"를 켜거나 `?ids=1`로 연다. 시계 줄에 `#번호`가 붙는다(실내면 그 건물, 밖이면 카메라가 보는 건물).
  - `?bld=HARBOR-0123`으로 열면 그 건물 옆에서 시작한다. 콘솔에서는 `__bld.go('V12-004')`, `__bld.find(...)`를 쓴다.
- 저장 키는 아직 예전 방식(목록 순번, `도시:i`, `마을:i`)이다. uid로 옮기는 것은 SAV-01에서 한다.
