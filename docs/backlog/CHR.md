- AC: 화면 속 20명 중 같은 외형(메시+색 조합) 비율이 현재 대비 크게 감소(측정 방식 착수 시 정의). `no-runtime-compile`, `boot` 녹색. 라이선스는 BLD-04 표에 등록.
- 의존: BLD-04(에셋 출처 관리), 사용자 확인(에셋 선택)
