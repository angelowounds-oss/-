#### CHR-06a 방향 이동 — Review · 2026-10-28
- 문제: 조준·전투 중에는 몸이 한쪽을 보고 다른 쪽으로 움직이는데 다리는 속도만 보고 앞으로 걷는 클립을 틀어 "문워크"가 됐다. 질주(8.4 m/s)는 달리기 클립을 1.7배로 늘려 썼다.
- 결과:
  - 다리 클립을 몸 방향 기준 이동 방향으로 고른다. 앞(속도에 따라 Walk → Run → Sprint), 뒷걸음, 좌우 옆걸음이 있다. 남는 각도만큼 엉덩이를 돌리고 척추는 되돌려(`turnHips`) 가슴과 조준은 앞을 유지한다.
  - 모든 다리 클립은 한 걸음 위상(왼발 디딤 중심)에 맞춰 재생된다. 재생 속도는 로딩 때 몸마다 잰 걸음 표(위상 96칸의 이동 거리)로 정해, 디딘 발이 땅에 머물게 한다(distance matching).
  - 측정해 보니 파일의 `Strafe_left`는 몸을 **오른쪽**으로 옮긴다. 그래서 클립 방향은 이름이 아니라 측정값으로 정한다.
- 수치(디딘 발 지면 속도 중앙값, m/s, 전 → 후):

  | 경우 | 전 | 후 |
  |---|---|---|
  | 걷기 1.4 | 0.16 | 0.01 |
  | 조준 앞 2.6 | 0.48 | 0.02 |
  | 조준 오른쪽 2.6 | 3.37 | 0.48 |
  | 조준 왼쪽 2.6 | 3.34 | 0.88 |
  | 조준 뒤 2.6 | 4.73 | 0.11 |
  | 조준 앞오른쪽 2.6 | 1.88 | 0.19 |
  | 달리기 5.2 | 0.09 | 0.17 |
  | 질주 8.4 | 0 (Run 클립) | 0 (Sprint 클립) |

  전 값은 발목만 본 판정이고, 후 값은 발목·발끝 중 낮은 쪽을 본 판정이다.
- 한계: 옆걸음 클립은 두 발이 다 땅에 있을 때 서로 반대로 미끄러진다. 재생 속도로는 못 고치므로 CHR-06c의 발 고정(IK)에서 마무리한다(그때까지 테스트 기준 0.9). 여성 전용 걷기·달리기 클립(`Walk_Female`·`Run_Female`)은 쓰지 않는다. Run_Female의 자연 속도는 3.8 m/s로 게임의 달리기 5.2 m/s와 멀고, Walk_Female의 엉덩이 흔들림은 조준과 어울리지 않는다.
- 성능: 군중 120명(모두 35 m 안), 렌더를 끈 `animateSkinned` 시간이 프레임당 5.26 → 5.64 ms(중앙값, 측정 흔들림 ±1 ms).
