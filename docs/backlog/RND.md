# RND — 렌더링

현재: L3, **정체(계측 대기)**. 손실 없는 최적화(컬링, 원경 인스턴스 패킹, 조명 루프 생략, 셰이더 프리컴파일, 그레이드 병합)는 완료되었고
`render` 스위트가 픽셀 동일성을 지킨다. 이 환경(SwiftShader)에서는 GPU 시간을 잴 수 없으므로 다음 결정은 PERF-01/02의 실기기 데이터로 한다.

불변 조건(깨면 안 됨): ADR-0002(조명 수 고정·플레이 중 컴파일 0), ADR-0005(인스턴스 패킹은 도시 안 저고도에서만).

### RND-02 그림자 비용 — P1 · M · M3 · Blocked (PERF-02 데이터)
- 배경: 2048 PCF-soft 한 장, ±85 m, 매 프레임 갱신. 그림자 패스가 GL 호출의 약 17%.
- 후보: 정적 그림자 캐시 + 동적 캐스터만 갱신, 또는 2단 캐스케이드(근거리 고해상도 / 원거리 저빈도). 실기기에서 그림자 패스가 프레임의 20%를 넘을 때만 착수.
- AC: 그림자 패스 GPU ms 30% 이상 감소, 근거리 품질 동일(스크린샷 비교에서 플레이어 주변 20 m 차이 0 또는 ADR로 허용 기준 기록).

### RND-03 저사양 후처리 경로 — P1 · M · M3 · Blocked (PERF-02 데이터)
- 범위: LOW 품질에서 블룸 절반 해상도·단계 축소, SMAA 대신 FXAA. 품질 단계별 차이를 문서화.
- AC: 중급 모바일에서 후처리 GPU ms 40% 감소.

### RND-04 차량·인물 원거리 LOD — P2 · M · Backlog
- 범위: 차량 원거리 단순 메시(바퀴·내장 생략), 인물은 CHR-03(임포스터)과 연계.

### RND-05 도시 밖 원경 컬링 — P2 · S · Backlog
- 배경: 인스턴스 패킹은 도시 밖·고도 20 m 이상에서 꺼진다(완전 안개 물체도 하늘 돔 앞에서 실루엣으로 보이기 때문). 외곽 숲 7,000그루가 그때 전부 그려진다.
- 후보: 하늘 돔 하단을 안개색으로 맞추는 지평선 처리(시각 변경 → 사용자 승인), 또는 "뒤가 지형인 인스턴스만" 컬링하는 고도-지평선 판정.
- AC: 외곽 도로 시점에서 픽셀 동일(또는 승인된 시각 변경)로 원경 삼각형 50% 감소.
