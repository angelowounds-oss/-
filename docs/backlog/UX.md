### UX-06 로딩 화면 "Purge Day" 디자인 적용 — P1 · S · Done (2026-10-11, `e2e/loading-screen`)
- 사용자가 준 목업(`Purge Day — 로딩`)을 로딩 화면에 적용: 사이렌 붉은 빛, 위쪽 경고 줄무늬(움직임), '긴급 방송' 표지 + 안내 문구(기존 두 줄을 합침), PURGE / DAY / 퍼지데이 큰 글자, 오른쪽 외곽선 퍼센트 숫자와 `T-00:xx` 카운트다운, 상태 줄(깜빡이는 ■ + `p / 100`), 40칸 진행 막대, 주사선.
- 구현: 1280×720 무대를 창에 맞춰 축소(세로 화면은 720×1280 별도 배치), 진행률은 `Game.init`의 실제 보고를 따르고 사이에는 천천히 앞서가며(최대 7%p) 100%는 실제 준비 완료 때만. 준비되면 '아무 키나 누르거나 화면을 터치하세요'. 시작 버튼 `#go`는 투명한 전체 화면 버튼(터치·클릭 시작). 글꼴은 파일 안에 포함(`docs/ASSETS.md`).
- 줄무늬·사이렌은 `transform`/`opacity` 애니메이션이라 메인 스레드가 바쁜 로딩 중에도 계속 움직인다.
- 남은 일: 안내 문구를 세계관에 맞게 다듬기(지금은 기존 두 줄), 한글 글꼴 포함 여부 결정(용량 대비), 진행 단계 문구를 목업의 5단계 이름으로 바꿀지(지금은 `Game.init`의 실제 문구).
