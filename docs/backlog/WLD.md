# WLD — 월드·건물

현재: L2~L3, **개선 여지**. 불규칙 도시·보행자 거리·약 300동 입장·층 스트리밍(생성기, 프레임당 3 ms)·엘리베이터·벽 파괴·정전 구역·
외곽 지형/수역. 약점: 실내 반복감, 랜드마크 공간 부족, `building.js`(78 KB)에 계획·생성·가구·런타임·상호작용이 혼재.

불변 조건: ADR-0004(층 생성은 생성기 단계, 한 단계 8 ms 미만), ADR-0006(층 버퍼는 풀에서, dispose 시 반납).
보호 테스트: `floor-population`, `breach`, `entrance-holes`, `cull-identity`(interior), `pool-integrity`.

### WLD-01 `building.js` 분리 — P1 · L · 병행 · Backlog
- 범위: (a) `plan`(층·방 배치, 순수 데이터 — Node에서 단위 테스트 가능) (b) 지오메트리 생성(벽·슬래브·코어·트림) (c) 가구 배치(로비/상가/방) (d) 런타임(문·엘리베이터·조명 스위치) (e) 스트리밍(Buildings 관리자). 동작 변경 없음.
- AC: 파일당 30 KB 이하, `plan`에 Node 단위 테스트(같은 seed → 같은 계획), gameplay·render 스위트 녹색.

### WLD-02 랜드마크 실내 — P1 · M · M3 · Backlog
- 범위: 손으로 설계한 특별 층 3~5종(예: 클럽, 경찰서, 병원 병동, 옥상 바, 갱단 아지트)을 데이터 템플릿으로. GPL-01 루프와 연결되는 장소 우선.
- AC: 각 장소가 지도·휴대폰에 표시되고, 템플릿 데이터만으로 배치된다.
- 의존: GPL-01, WLD-01(c)

### WLD-03 실내 다양성 — P2 · M · Backlog
- 범위: 건물 종류·소득 수준별 팔레트·가구 세트·방 배치 규칙 변주(같은 seed 결정성 유지).
- AC: 무작위 20개 층 스크린샷의 "같은 방 배치" 비율 감소(측정 방법을 티켓 착수 시 정의).

### WLD-04 창밖 실내 표현 — P2 · S · Backlog
- 범위: 아직 지어지지 않은 층의 창에 인테리어 매핑(패럴랙스 큐브맵) 셰이더. 플레이 중 컴파일 0 유지(프리워밍 포함).

### WLD-05 코어 벽 탐침 실패 조사 — P2 · S · Backlog
- 배경: `breach` 테스트(2026-10-09)에서 최고층 탑 첫 타워층의 코어 남쪽 탐침 지점(`core.x0+3, core.z0+6.5`, 남향)에서 `wallAhead`가 벽을 찾지 못했다(코어 동쪽은 정상). 탐침 위치가 코어 배치와 맞지 않는 것인지, 그 면이 파괴 대상에서 빠진 결함인지 미확인.
- 범위: 코어 네 면 각각에서 `wallAhead`가 벽을 찾는지 확인하는 테스트로 확장, 결함이면 수정.
- AC: 코어 4면 모두 파괴 가능하거나, 불가한 면의 이유가 문서화(예: 엘리베이터 문 면).
