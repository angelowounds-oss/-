# ADR-0004 층 스트리밍은 생성기 단계(프레임당 3 ms)
- 상태: 채택(2026-10-09, 이전 라운드의 동기 생성 대체)
- 배경: 건물 층 하나를 짓는 데 25~45 ms가 걸려 걷거나 운전하다 새 건물에 다가갈 때마다 끊겼다.
- 결정: `buildFloorGen`이 벽·코어·조명·가구·주민·병합을 단계마다 `yield`하는 생성기이고, `Building.tick`이 프레임당 약 3 ms씩 진행한다(플레이어 층에 가까운 층부터). 플레이어가 서 있는 층처럼 지금 필요한 층만 동기로 끝낸다(`buildFloor`). 무거운 단일 호출(인물 모델 생성, 가구 병합 2.5만 정점 단위, 로비 가구)은 자기 단계를 가진다.
- 결과: (+) 건물 작업 최장 단계 45 ms → 8 ms 미만. (−) 층이 완성되기 전 짧은 시간 동안 일부 내용이 없다(출입구는 로비 완성 후에만 열림).
- 재검토 조건: Web Worker로 지오메트리를 만들 수 있게 구조를 바꿀 때(OffscreenCanvas/전송 가능한 버퍼).
