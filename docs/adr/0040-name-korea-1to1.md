# ADR-0040 이름을 KOREA 1:1로 바꾼다

## 상태
채택 (2026-10-31, BLD-08). 사용자 선택: 이름은 "전부 새 이름", 새 이름은 "KOREA 1:1 (Korea.exe)".

## 배경
- 월드가 가상의 네온시티에서 실제 축척(1:1)의 서울·인천과 전국으로 바뀐다(WLD-23b 이후, 계획은 ADR-0038·0039에 적는다).
- 폴더·실행 파일·zip·창 제목에 옛 이름(NeonCity)이 남아 있으면 받는 사람이 같은 게임의 옛 버전으로 오해한다.

## 결정
1. 빌드 폴더는 `dist/Korea/`(`Korea.exe` + `game/`), zip은 `dist/Korea-<날짜>-<커밋>.zip`이고 맨 위 폴더는 `Korea/`이다. ADR-0034의 구조는 그대로다.
2. 런처의 이름만 바뀐다: 데이터 폴더 `%LOCALAPPDATA%\Korea`, 앱 id `korea`, 내부 주소 `/__korea/{id,ping,bye}`. 페이지(`src/main.js`)와 런처가 같이 바뀌므로 섞어 쓰면 안 된다.
3. 페이지 제목과 로딩 화면은 "KOREA 1:1"이다.
4. 이 티켓에서 바꾸지 않는 것: 도시 id `neon`과 표시 이름(WLD-24c), 저장 키 `neon_city_v9`(WLD-23b-3에서 한 번만 올린다).

## 결과
- 옛 `%LOCALAPPDATA%\NeonCity`의 저장과 설정은 새 폴더로 넘어오지 않는다. 축척이 바뀌면 옛 저장은 어차피 쓸 수 없으므로(WLD-23b-3) 옮기는 코드를 만들지 않는다.
- ADR-0034 본문은 옛 이름 그대로 두는 역사 기록이다.
