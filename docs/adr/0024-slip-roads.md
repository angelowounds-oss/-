# ADR-0024 진출입로·연결 도로(`*_link`)

## 결정
- 컴파일러의 도로 종류에 `motorway_link`·`trunk_link`·`primary_link`를 더했다(KOR-R2). 한 차로 일방통행, 본선보다 낮은 설계 반경(50/40/30 m)과 조금 높은 경사 한도(0.08~0.09)로, 본선 바로 뒤에 깐다. 본선에서 갈라지는 끝은 이미 깔린 본선의 노면에 맞춰 붙는다(기존 `claimed` 규칙).
- 게임은 `r.hw`가 `*_link`인 선을 일반 간선 기록으로 다룬다(폭·차로·일방통행은 기록에 들어 있다). 고속·간선만 찾는 곳(연결로 목적지, 큰 도로 표시)은 그대로 본선만 본다.
- 교차 간격(ADR-0023)은 진출입로에도 같은 규칙이다. 본선과 20° 미만으로 갈라지거나 합쳐지는 곳은 합류로 본다.

## 결과(수도권)
- 도로 2,053 → 5,851선(진출입로 3,738선, 약 226 km). 진출입로 끝 7,476개 중 7,466개(99.9%)가 다른 도로에 이어져 있고, primary의 끊긴 끝은 33 → 12로 줄었다.
- 교차 간격 부족 1.2%, 경사는 본선 한도 안, 진출입로는 한도 0.08~0.09.
- region.bin 크기와 도로 수 증가에 따른 조각 생성 비용은 실기기에서 확인해야 한다.

## 한계
- 인터체인지의 시각(진출입 표지, 분기 노면 표시)은 KOR-R5에서. 교통 AI가 진출입로로 빠지는 길 고르기는 아직 본선 위주다.
