# ADR-0008 건물 파괴는 외관 인스턴스·병합 메시 조작으로 (메시 교체·새 재질 없음)

- 상태: 채택 (2026-10-10, GPL-08c)
- 맥락: 사용자가 "건물 전체가 불타서 무너지는 것"까지 요청했다. 건물 외관은 도시 전체가 한 InstancedMesh(`world.facade`, 건물당 받침·탑·왕관 2~3 인스턴스)이고, 입구·간판은 도시 단위 병합 메시, 옥상 소품·간판 일부는 `instCull`이 패킹하는 인스턴스다. 건물별 메시를 새로 만들거나 새 재질을 쓰면 플레이 중 셰이더 컴파일(ADR-0002)과 드로우콜 증가가 생긴다.
- 결정:
  - 화재 표현은 외관 셰이더의 인스턴스 속성 `aBurn`(불 구간 아래·위, 열, 그을음 높이)으로 한다. 시작 시 컴파일되는 같은 프로그램이다.
  - 붕괴는 인스턴스 행렬을 프레임마다 바꿔 주저앉히고, 끝나면 받침을 잔해 높이로 줄이고 탑·왕관 행렬을 0으로 둔다. 원본 행렬은 시작 시 복사해 두고 재건 때 되돌린다.
  - 입구·간판 같은 병합 메시는 해당 구역의 정점을 땅 아래로 내리고 원래 높이를 기록해 둔다. 패킹 인스턴스는 `Packed.setMatrix`로 원본 목록과 GPU 슬롯을 함께 바꾼다.
  - 잔해 덩어리는 시작부터 장면에 있는 InstancedMesh 하나(480개, 색 버퍼 포함)를 링 버퍼로 쓴다. 불꽃·연기 파티클 두 개도 시작 시 만든다.
  - 충돌체는 건물 박스를 잔해 높이 박스로 바꾸고, 그 건물은 `ruined` 플래그로 다시 열리지 않는다.
- 결과: 붕괴 전후 셰이더 프로그램 수가 같다(`building-fire` 테스트, 74→74). 드로우콜은 잔해 메시 1개와 파티클 2개가 늘었다(항상).
- 한계: 실내 층(열린 건물)은 붕괴 시작 시 통째로 내린다(층별 붕괴 연출 없음). 원경(`far`)·모델 건물은 대상이 아니다. 병합 메시의 정점을 내리는 방식이라 구역 경계에 걸친 삼각형은 늘어날 수 있다(입구 구조물은 작아서 실제로는 생기지 않음).
