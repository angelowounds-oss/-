# ADR-0033 조작키: GTA V 배치 + 재지정 화면

## 상태
채택 (2026-10-28, UX-03a). 사용자 요청: "실제 유명 게임들을 참고해서 다시 조작키 맵핑 진행해". 사용자 선택: "GTA V 기준", "재지정 화면 추가".

## 배경
- 키가 파일마다 하드코딩돼 있었다(`input.js`, `main.js`, `phone.js`, `panels.js`, `worldmapui.js`, `transit.js`, 안내 문구 20여 곳).
- 겹치거나 죽은 키가 있었다:
  - P가 엎드리기와 일시정지를 동시에 했다.
  - K가 제스처 메뉴와 조작법을 동시에 열었다.
  - 조작법에 적힌 V(들기)·X(버리기)·N(앉기)는 아무 데도 연결돼 있지 않았다.
- 도움말(`#helpov`)은 손으로 쓴 목록이라 실제 키와 달랐다.

## 결정
- **한 곳에서 정한다(`src/keys.js`):**
  - 행동 id = `Input.edges` 이름. 기본 키는 최대 두 개.
  - 게임 코드는 키 코드를 직접 읽지 않고 `binds.is / held / label`만 쓴다. `unit/keys`가 `src/`의 하드코딩 키를 찾아 실패시킨다.
- **기본 배치는 GTA V(PC)를 따른다:**
  - W A S D, Shift 달리기, Space 점프·핸드브레이크, F 탑승·상호작용, E 경적·보조 행동, R 재장전, G 수류탄, V 시점, M 지도(J도), ↑ 휴대폰, Tab 무기·가방(I도), H 헤드라이트.
  - 웅크리기는 Ctrl 대신 **C**다. 브라우저에서 Ctrl+W는 탭을 닫고 페이지가 막을 수 없다.
  - 엎드리기 Z, 일시정지 P(와 Esc), 조작법 F1, 제스처 B, 항복 Y, 그래플 O(와 휠 클릭), 고도 유지 U.
  - 상호작용 동사 칸(F/G/T)은 행동 `use / horn / verb3`에 묶인다. 안내 문구는 지금 키 이름을 보여준다.
- **고정 키:** Esc(닫기·일시정지), 마우스 버튼·휠, 제스처 메뉴 안의 숫자, F9(샌드박스).
  - 지정할 수 없는 키: Esc, F5, F11, F12, Ctrl, Meta, 메뉴 키(`RESERVED`).
- **재지정 화면:**
  - 위치: 일시정지 메뉴 → "조작키 설정". 행동마다 두 칸이 있다.
  - 조작: 칸을 누르고 새 키를 누른다. Esc는 취소, Backspace는 칸 비우기(키가 하나뿐이면 비울 수 없음).
  - 이미 쓰는 키는 **서로 바꾼다**. 그래서 아무 행동도 키 없이 남지 않는다.
  - 키 입력은 window 캡처 단계에서 받아 게임 쪽에 전달하지 않는다.
  - 저장은 `localStorage` `neon_keys_v1`. 깨진 값이나 금지 키는 읽을 때 걸러진다.
- **도움말:** 열 때마다 바인딩으로 다시 쓴다(`renderHelp`).

## 결과
- 영향을 받은 테스트:
  - `e2e/water`의 잠수 키가 Z에서 C로 바뀌었다.
  - 다른 테스트는 행동 이름(`edges.use` 등)이나 `KeyW/KeyD/KeyJ/Space`를 쓰므로 그대로다.
- 바뀐 키(이전 → 지금):
  - 웅크리기 Z → C, 엎드리기 P → Z, 시점 C → V, 휴대폰 M → ↑, 지도 J → M(J 유지).
  - 상호작용 F/E → F, 보조 G → E, 수류탄 B → G, 헤드라이트 L → H, 경적 H → E.
  - 제스처 K → B, 조작법 K → F1.
  - 방향키 이동은 없앴다. ↑는 휴대폰이다(GTA V와 같다). 방향키로 움직이고 싶으면 재지정 화면에서 둘째 칸에 넣으면 된다.
- 기존 플레이어는 처음 한 번 새 배치로 시작한다. 이전 배치는 저장된 적이 없다.

## 대안
- **Ctrl 웅크리기(GTA 원본):** Ctrl+W·Ctrl+T 사고 때문에 기본값에서 뺐다. 재지정 화면에서 Ctrl은 금지 키다.
- **행동마다 키 하나:** 지도 M/J, 가방 Tab/I처럼 두 키를 원하는 경우가 있어 두 칸으로 했다.
