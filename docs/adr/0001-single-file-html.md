# ADR-0001 단일 HTML 파일 배포
- 상태: 채택(2026 초기) · 재검토 예정(PERF-05)
- 배경: 설치·서버 없이 파일 하나로 실행되는 배포를 원했다.
- 결정: esbuild로 모든 JS를 한 번들로, glb/jpg/rgbe 에셋을 base64·data URL로 HTML 안에 내장한다(`build/build.mjs`).
- 결과: (+) 파일 하나로 어디서나 실행. (−) 29.3 MB(원본 에셋 17.9 MB가 base64로 약 1.33배), 디코딩 동안 메모리 2배, 부분 캐시·스트리밍 불가, 저장소에 산출물을 커밋하면 이력이 급격히 커짐(`.git` 1.8 GB).
- 재검토 조건: 실기기 로딩 시간(PERF-02)이 목표를 넘거나, 에셋(캐릭터·오디오 샘플)이 더 늘어날 때. 후보: 멀티 파일 빌드 옵션 병행.
