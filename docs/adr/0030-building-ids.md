# ADR-0030 건물 고유번호와 목록

## 상태
채택 (2026-10-27, 사용자 요청: "유지보수하기 편하게 모든 건물마다 고유번호를 부여하고 리스트로 관리").

## 결정
- 모든 건물에 문자열 번호(uid)를 준다. 번호는 서 있는 곳(도시, 블록, 마을)과 그곳 생성기 안의 순서로 만든다. 같은 소스면 같은 번호이고, 다른 지역을 바꿔도 한 도시의 번호가 다시 매겨지지 않는다. 규칙은 `src/buildingid.js`와 `docs/buildings/README.md`.
- 목록 `docs/buildings/registry.csv`는 커밋한다(텍스트라 diff로 바뀐 건물이 보인다). 수도 배치는 브라우저에서만 만들어지므로 목록은 `tests/tools/building-registry.cjs`(Playwright)가 만든다. `--check`는 추가·삭제·이동을 보고한다.
- 생성기를 바꾸는 PR은 `--check` 결과를 본문에 적고, 목록을 다시 만들어 함께 커밋한다.
- 게임 안: `?ids=1` 또는 휴대폰 설정으로 번호 표시, `?bld=<uid>`와 `__bld.go(uid)`로 그 건물에 가기.
- 저장 키는 이번에 바꾸지 않는다(폐허 `state.ruins[목록 순번]`, 문·유리 `lot.id`, 다른 도시 `도시:i`, 마을 `마을:i`). uid로 옮기는 것은 저장 버전(SAV-01)과 함께 한다.

## 결과
- 2026-10-27 기준 16,936채(NEON 560, 다른 도시 15,551, 마을 780, 농장 16, 산업·통신 19, 휴게소 10), 중복 0.
- 단위 `building-ids`(수도 밖 전체와 수도 번호 규칙), 도구 `--check`(수도 포함 전체).
- 한계: 산업 단지는 단지 하나에 번호 하나다(안의 탱크·풍차는 단지 번호 아래 순번). 군 기지 담장·초소와 지하철 출입구 상자는 건물로 세지 않는다.
