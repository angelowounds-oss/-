# ADR-0005 손실 없는 최적화 원칙, 인스턴스 패킹 적용 범위
- 상태: 채택(2026-10-09)
- 배경: 사용자 요구가 "성능 저하(화질 저하) 없이 프레임 향상"이었다.
- 결정: 렌더링 최적화는 **같은 프레임을 두 방식으로 그려 픽셀이 같음을 테스트로 증명**할 수 있는 것만 기본 적용한다(컬링, 원경 인스턴스 패킹, 조명 루프 생략). 원경 인스턴스 패킹(`src/instcull.js`)은 안개가 99.95% 이상인 깊이(시야각 보정)를 넘는 인스턴스를 빼는데, 도시 밖·고도 20 m 이상에서는 완전히 안개에 잠긴 물체도 하늘 돔 앞에서 안개색 실루엣으로 보여 픽셀이 달라지므로 **도시 안 저고도에서만** 적용한다.
- 예외(의도된 시각 변경, 기록): 게임 중 HUD 패널 배경 블러 제거(합성 비용), 그레이드 패스 병합으로 인한 1 LSB 반올림 차이.
- 결과: (+) 최적화가 화질 회귀를 만들지 않음을 자동으로 보장. (−) 손실이 작아도 이득이 큰 최적화(LOD 등)는 별도 승인 필요.
- 재검토 조건: 저사양 기기 목표를 위해 품질 단계별 손실 허용 기준을 정할 때(RND-03).
