# ADR-0006 층 지오메트리 버퍼 풀링
- 상태: 채택(2026-10-09)
- 배경: 걷는 동안 층이 계속 지어지고 버려지며, 층마다 새 Float32Array(가구 병합만 층당 수 MB)를 만들었다. 이것이 새 ArrayBuffer 메모리의 96%였다.
- 결정: 층 Builder 출력(`B.pooled = true`)과 가구 병합 배열을 2의 거듭제곱 크기 풀(`takeF32`)에서 빌리고, 지오메트리 `dispose` 이벤트에서 한 번만 반납한다(`poolOnDispose`). 정적 월드 Builder는 풀을 쓰지 않는다(메모리 반올림 낭비 방지).
- 결과: (+) 25초 보행 중 새 버퍼 메모리 약 48 MB → 12.6 MB, 출력은 비트 동일(`builder-bitexact`). (−) 풀이 메모리를 붙잡는다(크기 클래스당 최대 8개). 버려진 층의 지오메트리를 다시 그리면 다른 층과 버퍼를 공유하게 됨 → `pool-integrity`가 감시.
- 메모: 메이저 GC 횟수는 줄지 않았다(주원인은 JS 힙 객체 승격) → PERF-04.
