# ADR-0007 테스트 전략: SwiftShader 동일성·로직 + 실기기 GPU
- 상태: 채택(2026-10-09)
- 배경: 개발 환경(클라우드 컨테이너)에 GPU가 없다. 헤드리스 Chromium의 SwiftShader는 정확한 픽셀을 그리지만 CPU 래스터라 GPU 시간이 의미 없고, 장면이 크면 JIT 캐시 스래싱으로 프레임당 1~2초 멈춘다.
- 결정: 자동 테스트는 (1) 픽셀 동일성(같은 프레임을 두 방식으로 그려 비교), (2) 로직·상태 검증, (3) **렌더를 끈** JavaScript 시간·할당 측정으로 한정한다. GPU 성능은 실기기 오버레이(PERF-01)와 기준선(PERF-02)으로만 판단한다.
- 결과: (+) 컨테이너에서 결정적으로 도는 회귀 스위트(`tests/run.cjs`). (−) GPU 회귀는 자동으로 잡지 못한다. 시간 기반 테스트는 머신 부하에 흔들리므로 임계값을 넉넉히 두고, 기준선 문서로 추세를 본다.
