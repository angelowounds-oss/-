# ADR-0028 고화질 에셋 팩과 라이선스 정책

## 상태
채택 (2026-10-27, 사용자 결정). ADR-0013(화질 2단계)을 넓힌다.

## 결정
- 배포: 게임 폴더(ADR-0034)의 본체 에셋(`game/assets/`, 노트북 화질)만으로 실행된다. 고화질 텍스처·모델·사운드는 KTX2/meshopt로 압축한 `game/world/assets.pak`에 두고, 화질이 고사양이면 불러온다(없으면 본체 에셋). 배포 폴더의 `game/LICENSES.txt`는 이 매니페스트로 만든다(`build/package.mjs`).
- 라이선스: CC0-1.0, CC-BY-3.0/4.0, OFL-1.1, MIT(코드), ODbL(지도 데이터)만 쓴다. GPL·NC·SA 계열(ODbL 데이터 제외)은 쓰지 않는다. GPL 물 셰이더 포팅은 교체한다(Q0-4).
- `USER-PERMITTED`: 사용자가 직접 제공하고 사용을 허용한 파일(2026-10-27, 원 라이선스 미상). 크레딧은 없고, 게임 밖 재배포 전에는 다시 확인한다. 새로 들이는 에셋에는 쓰지 않는다.
- 모든 외부 에셋은 `build/assets/manifest.json`에 출처·작가·라이선스·sha256과 함께 올리고, 크레딧과 `docs/ASSETS.md`는 그 목록에서 만든다. 목록 밖 에셋이나 허용 밖 라이선스는 빌드가 거부한다.
- 사운드: 효과음·환경음은 녹음 샘플(CC0/CC-BY), 음악과 UI는 합성 유지(AUD-00 결정).
- 받은 원본과 팩은 커밋하지 않는다(ADR-0013과 같음). 목록과 스크립트만 커밋한다.

## 결과
- 화질 상향(AAA-PLAN Q1~Q6)이 본체 크기 한도에 묶이지 않는다. 팩이 없는 환경도 지금 화질로 동작한다.
- 크레딧 화면이 의무가 된다(CC-BY·OFL·ODbL).
