# ADR-0003 고정 스텝 물리 + 렌더 보간
- 상태: 채택(2026-10-09)
- 배경: Rapier를 고정 1/60 s로 돌리고 마지막 상태를 그대로 그렸더니, 120/144 Hz 화면에서 차량·랙돌·던진 물건이 절반의 프레임에서 멈췄다가 두 칸씩 움직였다(60 Hz에서도 rAF 지터로 간헐적 0/2 스텝).
- 결정: 스텝 직전 자세를 보관하고, 누산기 잔여 비율 `Physics.alpha`로 이전·현재 자세를 보간해 그린다. 게임 로직은 시뮬레이션 위치(`v.x`), 화면·카메라·전조등·지붕 위 인물은 그려진 위치(`v.rx/rz/rh`). 순간이동(`syncToBody`, 뒤집힘 복구)은 보간을 끊는다.
- 결과: (+) 고주사율에서 매끄러움(`physics-interp`: 정지 프레임 50% → 0%). (−) 최대 1스텝(16.7 ms)의 시각 지연. 그려진 위치와 시뮬레이션 위치를 혼동하면 버그 → 위 규칙을 지킬 것.
- 재검토 조건: 물리 스텝을 가변으로 바꾸거나 120 Hz 물리로 갈 때.
