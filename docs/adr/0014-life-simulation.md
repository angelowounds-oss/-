# ADR-0014 생활 시뮬레이션: 결정론적 인물 + 변경분 저장 + 규칙 기반 사회

- 상태: 제안 (2026-10-17, 사용자 결정 반영. 구현은 `docs/prompts/LIFE-SIM.md` 단계별)
- 관련: ADR-0004(층 생성기 단계), ADR-0009(캐릭터 리그), ADR-0012(월드), `docs/backlog/LIFE.md`

## 맥락
지금 시민은 이름·나이·직업·집·직장·하루 일정을 가지지만(`citizens.js`), 관계·성격·대화 이력은 없다. 마을 주민(`village.js`)은
따로 등록되어 있고, 다른 도시의 행인(`citylife.js`)은 그때그때 만들었다가 버린다. 사용자는 GTA처럼 현실에 가까운 생활을 원한다:
연애·결혼·동거, 친구·동료, 원한·라이벌, 자녀, NPC끼리의 관계, 식사·드라이브·집 생활·행사.

## 사용자 결정 (2026-10-17)
| 항목 | 결정 |
|---|---|
| 중심 | 플레이어 관계를 먼저 만들고, 같은 관계 그래프로 NPC끼리 사회를 넓힌다 |
| AI | **규칙 기반만**. 외부 LLM·네트워크를 쓰지 않는다(단일 HTML, 오프라인) |
| 퍼지데이 | 생활 시스템은 퍼지와 분리한다. 퍼지는 기존 전투·범죄 시스템이 맡는다 |
| 깊이 | **등록된 모든 시민이 깊은 관계**를 가진다(성격·관계·기억·대화 이력) |
| 관계 종류 | 연애·결혼, 친구·동료, 원한·라이벌, 가족(자녀) 전부 |
| NPC끼리 | 가까이에서는 보이는 장면, 멀리서는 하루 단위 요약 계산 |
| 다른 도시 | 도시마다 등록 시민 명부(다시 가면 같은 사람) |
| 대화 | 선택지 대화 + 행동 메뉴 |

| 아이 모델 | 우선 성인 리그의 뼈 비율로 절차적으로 만들고, GLB를 받으면 교체 |
| 연애 대상 | 성인이면 성별 무관. NPC마다 선호가 있다. 미성년자는 대상에서 완전히 제외 |
| 사망 | 영구 사망 유지(가족·연인 포함). 위험하면 먼저 전화로 알리고 도망친다 |
| 1차 활동 | 식사·술·카페, 드라이브·산책, 집 생활, 행사·의식 |

## 결정
1. **인물 = 시드 기반 원본 + 변경분.** 모든 인물의 원본(이름, 성별, 생일, 성격, 취향, 가족, 초기 지인)은 `(지역 시드, 인물 번호)`의
   순수 함수다. 저장에는 원본과 달라진 필드만 남긴다(`G.state.people.d[id]`). 원본은 요청할 때 만들고 LRU 캐시에 둔다.
   그래서 약 5,800명(수도 2,000, 6개 도시 각 400~600, 마을 약 750, 농장)이 모두 깊은 관계를 가져도 저장과 메모리가 작게 유지된다.
2. **관계 = 간선 그래프.** 간선은 `(a, b)` 하나에 축 몇 개(호감, 신뢰, 끌림, 친숙도, 원한)와 단계(가족·연애·친구 등)를 둔다.
   초기 간선(가족, 동거인, 동료, 이웃, 오래된 친구)은 원본에서 계산한다. 바뀐 간선과 플레이어 간선만 저장한다.
   접촉이 없으면 값이 줄어드는 감쇠는 매일 돌리지 않고 읽을 때 `lastDay`로 계산한다.
3. **위치·일정은 계속 시간의 순수 함수다.** 일정 = 원본 일정(요일·직업·나이) ⊕ 덮어쓰기 구간(데이트, 방문, 행사, 이사)이다.
   멀리 있는 사람은 프레임마다 갱신하지 않는다.
4. **사회 틱은 하루 한 번, 나눠서 계산한다.** 게임 하루가 바뀌면 지역별 큐에 사람을 넣고 프레임당 예산(≤ 1 ms) 안에서
   NPC끼리의 사건(만남, 친해짐, 연애, 결혼, 이별, 이사, 출생, 노환 사망, 이직)을 굴린다. 결과는 뉴스·소문·휴대폰 알림이 된다.
5. **보이는 장면은 가까운 사람에게만 만든다.** 아는 사이인 두 사람이 가까이 있고 둘 다 실체화되어 있으면, 인사·대화·함께 걷기·다툼·
   포옹·같이 식사 장면을 만든다. 동시에 최대 6개. 기존 클립(`Idle_Talking`, `Interact`, `Sitting_*`, `Push`, `Dance_Simple`)에
   뼈 오프셋으로 만든 절차적 자세(손 흔들기, 포옹, 손잡기)를 더한다. 새 셰이더는 만들지 않는다.
6. **대화는 규칙 기반 문법이다.** 의도(인사, 잡담, 칭찬, 농담, 고민 듣기, 선물, 부탁, 데이트 신청, 고백, 청혼, 사과, 협박, 모욕)마다
   결과는 성격 궁합 × 기분 × 관계 단계 × 상황(시간, 장소, 수배, 최근 기억)으로 정한다. 대사는 한국어 템플릿에 값을 채우고,
   조사(은/는, 이/가, 을/를)와 말투(존댓말/반말: 나이 차이·친밀도)를 맞춘다.
7. **아이·청소년은 보호 대상이다.** 미성년자는 연애 대상에서 제외하고, 협박·모욕 선택지를 쓸 수 없다. 사격·폭발·차량 피해를 받지 않는다.
   AI는 미성년자를 공격 대상으로 고르지 않는다. 위험이 생기면 실내나 보호자에게 피한다. 화면에서 다치거나 죽는 묘사는 없다.
   노환·사고 사망은 성인에게만 일어난다.
8. **아이 성장 배속.** 1년 = 28일이면 성인까지 약 200시간이 걸린다. 그래서 0~17세는 4배속으로 나이를 먹는다
   (아이 1살 = 게임 7일, 성인까지 약 50시간). 성인은 1배속이다.

## 결과
- 좋은 점: 오프라인, 결정적, 저장 크기 예측 가능(변경분만), 멀리 있는 사람의 비용 0, 기존 `citizens`·`memory`·`society`를 재사용.
- 비용: 대사 은행과 규칙표가 커진다(데이터 파일로 분리: `src/data/lines/*.js`, `src/data/social.js`). 자유 대화는 불가.
- 위험: 저장 크기 증가(SAV-01 스키마 버전 선행 필수), 사회 틱이 프레임을 넘김(예산·측정 테스트), 동시 장면이 AI 비용을 키움(상한 6).
