# 성능 기준선

성능 관련 변경 후에는 이 표와 비교하고, 수치가 바뀌면 갱신한다(날짜·커밋·환경 명시). **실기기 기준선은 아직 없다**(PERF-01/02).

## A. 컨테이너 기준선 (자동 테스트) — 2026-10-09, `ebe2e86` + 테스트 이식
환경: 클라우드 컨테이너 4코어, 헤드리스 Chromium + SwiftShader(WebGL2 CPU 래스터), 품질 MEDIUM(`?q=1`), 렌더를 끈 JS 시간.
GPU 시간은 이 환경에서 의미가 없다(ADR-0007).

| 항목 | 값 | 테스트 |
|---|---|---|
| 프레임 JS 시간, 걷기 7 m/s 1,500프레임 | 중앙 2.1 ms · p99 9.6 ms · 최대 32.3 ms · 33 ms 초과 0 | `frame-time` |
| 프레임 JS 시간, 주행 1,500프레임 | 중앙 2.1 ms · p99 8.6 ms · 최대 133.7 ms(1회) · 33 ms 초과 1 | `frame-time` |
| 연사 중 사람 갱신 | 1.05 ms/프레임(연사 전 1.06) · 프레임 p90 4.1 ms | `gunfire-load` |
| 경로 탐색 160건 | 평균 0.66 ms · p95 3 ms · 최대 24 ms · 성공 120/160 | `nav-perf` |
| 144 Hz 차량 이동 | 그려진 위치 정지 프레임 0/10,248 (시뮬레이션 위치는 5,990) | `physics-interp` |
| 첫 화면 (480×360, MEDIUM) | 드로우콜 243 · 삼각형 86만 · 셰이더 73개 | `boot` |
| 원경 인스턴스 패킹 | 도시 시점에서 정적 인스턴스의 26%만 그림 | `pack-identity` |
| 플레이 중 셰이더 컴파일 | 0 | `no-runtime-compile` |
| 층 생성 | 탑 문 앞 15초에 4개 층 · 건물 작업 한 단계 최대 7.9 ms | `floor-population`, 수동 계측 |

## B. 메모리·GC (수동 계측, 2026-10-09)
같은 환경, 걷기 1,500프레임(렌더 없음), Chrome 트레이싱·힙 샘플링.

| 항목 | 값 | 비고 |
|---|---|---|
