# 성능 기준선

성능 관련 변경 후에는 이 표와 비교하고, 수치가 바뀌면 갱신한다(날짜·커밋·환경 명시). **실기기 기준선은 아직 없다**(PERF-01/02).

## A. 컨테이너 기준선 (자동 테스트) — 2026-10-09, `ebe2e86` + 테스트 이식
환경: 클라우드 컨테이너 4코어, 헤드리스 Chromium + SwiftShader(WebGL2 CPU 래스터), 품질 MEDIUM(`?q=1`), 렌더를 끈 JS 시간.
GPU 시간은 이 환경에서 의미가 없다(ADR-0007).

## D. 100 km 월드 (ADR-0012, 2026-10-16, 같은 컨테이너, MEDIUM, 렌더를 끈 JS 시간 / 한 프레임의 GPU 입력) — 테스트 `world-perf`
| 장소 | JS 중앙 / p99 / 최대 (ms) | 드로우콜 · 삼각형 |
|---|---|---|
| 수도 거리 | 4.7 / 18.6 / 26 | 371 · 134만 |
| 다른 도시 거리(거리 생활 켜짐) | 4.7 / 13.5 / 27 | 309 · 141만 |
| 항만 도시 거리 | 5.4 / 18 / 33 | 341 · 159만 |
| 고속도로 | 4.9 / 13.4 / 22 | 393 · 114만 |
| 도시 횡단 900프레임(4 m/프레임, 타일 생성 포함) | 5.3 / 36.2 / 78 | — |

- 새 월드의 정적 비용(수도 거리): 원경 지형 6.2만 삼각형·10콜, 고속도로 3.2만·79콜(11 km 밖 청크는 거리 컬), 철도 0.4만·6콜. 시작: 구운 데이터 풀기 약 0.1 s, 고속도로 0.28 s, 도시 6곳 메시 0.9 s, 이동 0.07 s(이 환경).
- 이동(지하철·철도·항공·택시) 중 프레임 최대: 17~90 ms(건물 열기·교통·거리 생활을 멈춤).
- 타일 하나 만들기(근거리 L0): 최대 14 ms. 원경 지형 점프 후 층 하나 재생성: 약 30 ms(프레임당 6 ms 예산으로 가까운 층부터).
