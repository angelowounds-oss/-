# 대한민국 월드 작업 목록 (KOREA-PLAN)

목표(사용자): 대한민국과 최대한 동일한 지형을 만들고, 행동·물체·탑승·지형·고도·수심 등 약 1000가지를 현실과 가깝게 구현한다. 단, 퍼지데이의 본질(밤의 무법 도시 서바이벌)은 놓치지 않는다.
이 파일이 진행의 기준이다. 항목을 끝내면 `[x]`로 바꾸고 커밋 해시와 수치를 적는다. 티켓 규칙은 `docs/ROADMAP.md`, 세부 티켓은 `docs/backlog/WLD.md`.

기준: 맵 좌표 = 로컬 + CAPITAL(−10741, −28553). 투영 방위등거리(127.77E, 35.9N), 1:6.5(`KOREA_SCALE`). 높이 격자 `CG=256`(셀 390.625 m 맵 = 약 2.5 km 실거리). 결정 근거는 `docs/adr/0017-*.md`.
각 항목은 **방법**(어떻게 만드는가), **검증**(무엇으로 맞다고 증명하는가), **완료**(수치 기준)로 적는다. 검증은 가능하면 `tests/unit/*.test.mjs`에 자동화한다.

## 공통 규칙
- DoD: `node build/build.mjs` → `node tests/run.cjs quick`(월드·렌더면 `all`) 통과, 백로그 상태 갱신, 구운 데이터와 빌드 산출물은 커밋하지 않음(ADR-0013), 새 에셋은 `docs/ASSETS.md`에 출처·라이선스.
- 불변 조건(`docs/ARCHITECTURE.md` §3): 플레이 중 셰이더 컴파일 0, 물리 보간(로직은 `v.x`, 화면은 `v.rx`), 층 생성 단계 8 ms 미만, 렌더 최적화는 픽셀 동일, 풀 버퍼는 한 번 반납.
- 이 환경에는 GPU가 없다: 성능은 JS 시간·할당·삼각형/드로우콜로만 주장한다.
- 실제 자료로 맞추는 모든 항목은 같은 방식으로 검증한다: **실제 값(위경도·고도·거리)을 표로 적고, `project()`로 맵 좌표로 바꿔, 게임 함수가 허용 오차 안에서 같은 값을 내는지** 단위 테스트로 대조한다(`unit/korea-match` 방식, 오차는 한 노드 = 390 m 맵 = 2.5 km 실거리 안팎).
- 자료 출처와 라이선스는 받는 즉시 `docs/ASSETS.md`에 적는다. 큰 원자료는 저장소 밖(`build/.osm-cache/` 등)에 두고, 게임에 넣는 파생 자산만 커밋한다.

  - 검증: 모든 "없음" 항목에 티켓 ID가 붙음(`catalog` 테스트가 검사).
  - 완료: 티켓 미연결 0.

- [ ] **F4 묶음별 구현과 검증**
  - 방법: 티켓 하나씩 `feat/<ID>-<설명>` 브랜치 규칙으로 구현. 각 묶음마다 최소 하나의 단위/e2e 검증과 상태 갱신.
  - 검증: 해당 테스트 + quick, 카탈로그 상태 갱신 후 `catalog` 테스트.
  - 완료: 묶음마다 "있음"으로 바뀐 개수 기록.
