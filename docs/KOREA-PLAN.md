# 대한민국 월드 작업 목록 (KOREA-PLAN)

목표(사용자): 대한민국과 최대한 동일한 지형을 만들고, 행동·물체·탑승·지형·고도·수심 등 약 1000가지를 현실과 가깝게 구현한다. 단, 퍼지데이의 본질(밤의 무법 도시 서바이벌)은 놓치지 않는다.
이 파일이 진행의 기준이다. 항목을 끝내면 `[x]`로 바꾸고 커밋 해시와 수치를 적는다. 티켓 규칙은 `docs/ROADMAP.md`, 세부 티켓은 `docs/backlog/WLD.md`.

기준: 맵 좌표 = 로컬 + CAPITAL(−10741, −28553). 투영 방위등거리(127.77E, 35.9N), 1:6.5. 결정 근거는 `docs/adr/0017-*.md`.

## 승인된 결정
- [x] 도시 간격은 발자국 반경 합의 1.5배 (2026-10-19)
- [x] OSM 도로(ODbL) 내장, 크레딧 표기, 파생 자산 동일 조건 공개 (2026-10-19)

- [ ] A2 국도 생성기 복구: 90개 연결 중 17개만 길이 생김(91 km, 이전 333 km). 단면 경사 제한 0.13이 과함. 완화·비용식으로 바꿔 커버리지 회복, `unit/countryroads-quality` 유지

- [ ] A5 게임 안 크레딧 화면에 © OpenStreetMap contributors (ODbL), SRTM/Terrarium, KOSTAT 표기

## B. 지형 (2단계 이어서)
- [ ] B1 실제 강 경로: 한강, 낙동강, 금강, 영산강, 섬진강, 형산강 등을 중심선으로 굽는다(OSM waterway 또는 수계 자료). 폭·수심 포함, 하구는 바다로 이어짐
- [ ] B2 한라산 화구, 백록담, 오름, 제주 해안 용암 지형 / 울릉도·독도 / 백두대간 능선 확인 (DEM 해상도 한계는 상세 노이즈로 보강)
- [ ] B3 서해 갯벌(조수), 동해 급경사 해안, 남해 다도해, 섬 목록(강화·영종·거제·진도·완도 등)
- [ ] B4 수심: 대륙붕 수심 곡선(서해 얕음 ~50 m, 동해 깊음 ~3000 m)을 실제 해저 자료로 맞춤
- [ ] B5 호수·저수지·댐(소양강·충주·팔당·대청·안동)
- [ ] B6 바이옴: 한라산 화산 바이옴을 실제 위치로, 침엽/활엽 분포, 논밭(호남·김포 평야), 간척지(새만금)
- [ ] B7 지형 대조 테스트 확장: 산 정상 20곳, 강 교차점, 해안선 대조 (`unit/korea-match`)
