# V8 Motion Lab

A single-file, mobile-first V8 engine interactive that presents a modern high-performance cutaway engine with swipe orbit controls and an RPM slider.

## Run

Open `index.html` directly in a modern browser.

## Experience

- Mobile-friendly swipe orbit interaction
- RPM slider from idle to high revs
- High-detail cutaway rendering in a single HTML file
