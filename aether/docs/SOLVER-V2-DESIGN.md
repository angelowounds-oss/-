# 솔버 V2 재설계안

**사용자 결정(2026-10-09)**: ① 방식은 LBM과 투영법 **둘 다 시제품을 만든 뒤 같은 벤치마크로 비교해 결정**, ② **정확도 우선**(오프라인 고해상도로 합격 후 실시간은 같은 솔버의 저해상도판), ③ 기존 MAC은 **폴백으로 유지**.

## 0. 시제품 비교(S0) 절차
- CPU 기준 구현(Node, `tools/solver2/`), 두 방식 모두 같은 형상·조건·격자 3단계(D/h = 10, 20, 40).
- 벤치마크 1: Schäfer–Turek 2D-1(원기둥, Re 20, 정상 상태) — Cd 5.5795, Cl 0.0106, Δp 0.1175(문헌 범위 Cd 5.57~5.59, Cl 0.0104~0.0110, Δp 0.1172~0.1176).
- 벤치마크 2(1을 통과한 방식만이 아니라 둘 다): 구 Re 100(Cd 약 1.09).
- 판정 지표: 격자별 오차, 관측 수렴 차수, 같은 오차에 드는 계산량, 안정성, GPU 이식 난이도.


## 1. 왜 다시 만드는가 (측정된 문제)
| 문제 | 근거 |
|---|---|
| 절대 Cd가 약 2배 높음 | Ahmed 25° 문헌 0.285 대비 0.63~0.80 (`tests/ahmed.mjs`, L36) |
| 격자를 줄여도 문헌 방향으로 수렴하지 않음 | BMW 0.60 → 0.78 → 1.10 (셀 34 → 25 → 18 cm, `data/reference/runs`) |
| 격자 수가 8의 배수가 아니면 압력 풀이 발산 | MID 181×43×70에서 측정(이번에 기본값 수정) |
| 균일 격자라 차 주변 해상도를 올리면 터널 전체 비용이 함께 커짐 | HIGH 11 s/스텝, ULTRA 로드 실패 |
| 차 밑 틈(7~10 cm)·경계층을 해상하지 못함 | 셀 18~34 cm |

정리하면, 현재 구조(균일 격자 + 전역 압력 푸아송 + 부분체적 경계)로는 차 주변만 촘촘히 할 수 없고, 촘촘히 해도 경계 처리 오차가 줄지 않습니다.

## 2. 목표와 합격 기준 (측정 가능해야 함)
| 단계 | 기준 |
|---|---|
| 기초 검증 | 푸아죄유 유동 속도 분포 오차 < 1 %, 2차 정확도 확인(격자 2배 → 오차 1/4) |
| 원기둥(Schäfer–Turek 2D-1, Re 20) | Cd 5.58 ± 3 %, Cl, Δp 문헌 범위 |
| 구(Re 100 / 300) | Cd 문헌 ± 5 % |
| Ahmed 25° (Re ~ 7.7e5 상당, 벽 모델) | 오프라인 고해상도 Cd 0.285 ± 15 %, 격자를 줄일수록 문헌 쪽으로 단조 수렴 |
| 실시간(저해상도) | 같은 솔버·같은 경계 처리, 정확도는 낮아도 수렴 추세상 같은 방향 |
| 차량(BMW·Agera) | 같은 조건에서 두 차의 상대 순서가 안정적(격자 2단계 이상에서 같은 순서) |
실제 풍동 값과 같아진다는 보장은 하지 않습니다. 기준은 공개 벤치마크로만 판정합니다.

## 3. 방식 선택
| 항목 | A. 격자 볼츠만(LBM) 재설계 **권장** | B. 투영법(현행 MAC) 재설계 |
|---|---|---|
| 차 주변 국소 세분화 | 2:1 중첩 블록이 표준 기법(자동차 공력 상용 툴 PowerFLOW 계열) | 중첩 격자에서 전역 푸아송을 합성 멀티그리드로 풀어야 함(복잡) |
| GPU 적합성 | 셀마다 이웃만 읽음, 전역 풀이 없음 | 압력 풀이가 비용의 대부분, 전역 통신 |
| 이전 시도의 문제 | M7: 계단 경계(+43 % Cd) → **보간 경계(Bouzidi)로 해결 가능**한 원인 | 현재의 2배 오차 원인(경계·힘 계산·수렴) 미규명 |
| 단점 | 마하수 제약으로 스텝 수 많음, 메모리 큼(19~27 분포) | 기존 코드 재사용 가능 |
| 이동 벽(바퀴·롤링 로드) | 이동 벽 bounce-back으로 처리(새로 구현) | 이미 있음 |

## 4. 권장 구조 (A안)
- 격자: D3Q27, 누적량(cumulant) 충돌 연산자(낮은 점성에서 안정) — 안정성 문제 시 정규화 BGK로 대체.
- 경계: 보간 bounce-back(Bouzidi, 표면까지의 실제 거리 사용), 이동 벽 지원, 입구 속도·출구 압력·흡수층.
- 난류: LES(WALE 또는 Smagorinsky) + 벽 모델(벽 근처 속도를 로그 법칙으로 보정).
- 힘: 운동량 교환법(표면 링크 단위) — 압력·마찰을 표면 지도로도 출력.
- 국소 세분화: 2:1 중첩 블록 4~5단계(터널 32 cm → 차 표면 근처 2~4 cm).
- 개발 순서: **CPU 기준 구현(Node, 다중 스레드) → 벤치마크로 검증 → GPU(WebGL2) 이식 → CPU와 같은 결과인지 비교**. 이 환경에는 GPU가 없고 WebGPU도 쓸 수 없어서, 정확도는 CPU 기준 구현으로, GPU 이식은 소형 격자에서 CPU와의 일치로 검증합니다.
