# 솔버 V2 재설계안

**사용자 결정(2026-10-09)**: ① 방식은 LBM과 투영법 **둘 다 시제품을 만든 뒤 같은 벤치마크로 비교해 결정**, ② **정확도 우선**(오프라인 고해상도로 합격 후 실시간은 같은 솔버의 저해상도판), ③ 기존 MAC은 **폴백으로 유지**.

## 0. 시제품 비교(S0) 절차
- CPU 기준 구현(Node, `tools/solver2/`), 두 방식 모두 같은 형상·조건·격자 3단계(D/h = 10, 20, 40).
- 벤치마크 1: Schäfer–Turek 2D-1(원기둥, Re 20, 정상 상태) — Cd 5.5795, Cl 0.0106, Δp 0.1175(문헌 범위 Cd 5.57~5.59, Cl 0.0104~0.0110, Δp 0.1172~0.1176).
- 벤치마크 2(1을 통과한 방식만이 아니라 둘 다): 구 Re 100(Cd 약 1.09).
- 판정 지표: 격자별 오차, 관측 수렴 차수, 같은 오차에 드는 계산량, 안정성, GPU 이식 난이도.

## S1 결과 (사용자 결정 2026-10-10: 세 항목 모두 진행)
구현: `tools/solver2/core3d.mjs`, `core3d-kernel.mjs`, `core3d-worker.mjs`. 시험: `tools/solver2/tests/` (mt-equivalence, stability, acoustic-reflection), 벤치: `bench/sphere3d.mjs`(환경변수 `AETHER_MODEL=trt|reg|regles`, `AETHER_SPONGE=출구D,입구D,강도`).

### S1-1 다중 스레드 (worker_threads + SharedArrayBuffer, z 슬랩 분할, 단계마다 장벽)
- 단일 스레드 TRT와 **모든 유체 셀의 분포함수가 비트 단위로 일치**(300스텝, 차이 0개), 항력 상대 차이 2.7e-15.
- 속도(4코어, 같은 환경): 4스레드 TRT 15~19 MLUPS(단일 스레드 4.2~5.5), 정규화 충돌 약 10 MLUPS. 구 Re 100 D/h=10 계산이 21분 → 4.5분.
- 알려진 한계: 코어 4개 기준으로만 측정. 벽시계 시간은 CPU 점유율에 따라 달라짐.

|---|---|---|---|---|---|
| TRT | 안정 | **발산**(504스텝) | 발산 | 발산 | 발산 |

- 구(D=10칸, 격자 속도 0.06, 24 D/U 동안) 시험. **안정하다는 것이 정확하다는 뜻은 아님**: D=10칸에서 Re 300·1000의 Cd는 0.87~0.91, 0.68~0.72로 문헌(약 0.66, 0.47)보다 30~50 % 높음(해상 부족 + 막힘률 4.9 % + 미수렴). 정확도는 S2(해상된 벤치마크, 벽 모델)에서 판정.

- 층류(Re 100)에서는 Smagorinsky가 점성을 더해 Cd를 올림(D/h=10: 정규화 1.2491 → 1.2724, +1.9 %). 해상된 층류 시험은 Cs = 0으로.

### S1-3 흡수층
- 방식: 층 안에서 분포함수 전체를 자유류(ρ = 1, u = (U, 0, 0))로 완화(강도 σ, 층 끝 쪽으로 2차 증가). 밀도만 완화하는 방식은 효과가 작아 폐기(반사 0.8 → 0.16).
- 평면 음향 펄스 반사율(`acoustic-reflection.mjs`, 정규화 충돌): 층 없음 출구 −0.80 / 입구 +0.81. 층 40칸·σ 0.1: **|R| = 0.007**, 60칸·σ 0.1: 0.001. 점성 증가(dtau)는 효과가 거의 없어 기본값 0.
- **입구 층은 Cd를 올림**(구 Re 100, D/h=10, TRT):
| 층 | Cd | 스텝 |
|---|---|---|
| 없음 | 1.2054 | 12,201 |
| 출구만(2.5 D) | 1.2056 | 5,976 |
| 입구만(1 D) | 1.2216 | 8,881 |
| 입구+출구 | 1.2229 | 5,146 |
  넓은 상자(막힘률 0.8 %)에서도 입구 층의 +1.8 %가 남아 막힘 효과가 아님(원인은 추정: 입구 근처 유동을 자유류에 고정해 구가 상류에 만드는 감속·압력 상승을 막음). → **기본 설정은 출구 층만(2.5 D, σ 0.1)**. 입구 반사는 한 번 반사된 뒤 출구 층이 흡수.
- 출구 층은 정확도를 바꾸지 않고 수렴 스텝을 절반으로 줄임.

## 1. 왜 다시 만드는가 (측정된 문제)
| 문제 | 근거 |
|---|---|
| 절대 Cd가 약 2배 높음 | Ahmed 25° 문헌 0.285 대비 0.63~0.80 (`tests/ahmed.mjs`, L36) |
| 격자를 줄여도 문헌 방향으로 수렴하지 않음 | BMW 0.60 → 0.78 → 1.10 (셀 34 → 25 → 18 cm, `data/reference/runs`) |
| 격자 수가 8의 배수가 아니면 압력 풀이 발산 | MID 181×43×70에서 측정(이번에 기본값 수정) |
| 균일 격자라 차 주변 해상도를 올리면 터널 전체 비용이 함께 커짐 | HIGH 11 s/스텝, ULTRA 로드 실패 |
| 차 밑 틈(7~10 cm)·경계층을 해상하지 못함 | 셀 18~34 cm |

정리하면, 현재 구조(균일 격자 + 전역 압력 푸아송 + 부분체적 경계)로는 차 주변만 촘촘히 할 수 없고, 촘촘히 해도 경계 처리 오차가 줄지 않습니다.

| 항목 | A. 격자 볼츠만(LBM) 재설계 **권장** | B. 투영법(현행 MAC) 재설계 |

## 4. 권장 구조 (A안)
- 격자: D3Q27, 누적량(cumulant) 충돌 연산자(낮은 점성에서 안정) — 안정성 문제 시 정규화 BGK로 대체.
- 경계: 보간 bounce-back(Bouzidi, 표면까지의 실제 거리 사용), 이동 벽 지원, 입구 속도·출구 압력·흡수층.
- 난류: LES(WALE 또는 Smagorinsky) + 벽 모델(벽 근처 속도를 로그 법칙으로 보정).
- 힘: 운동량 교환법(표면 링크 단위) — 압력·마찰을 표면 지도로도 출력.
- 국소 세분화: 2:1 중첩 블록 4~5단계(터널 32 cm → 차 표면 근처 2~4 cm).
- 개발 순서: **CPU 기준 구현(Node, 다중 스레드) → 벤치마크로 검증 → GPU(WebGL2) 이식 → CPU와 같은 결과인지 비교**. 이 환경에는 GPU가 없고 WebGPU도 쓸 수 없어서, 정확도는 CPU 기준 구현으로, GPU 이식은 소형 격자에서 CPU와의 일치로 검증합니다.
