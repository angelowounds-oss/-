# 사용성 진단 (V22, 2026-10-28)

## 진단 방법
`tests/ux-walk.mjs`로 실제 탭과 클릭을 하며 전체 동선을 따라갔습니다.
- 동선: 첫 화면 → 입장 → 시네마틱 → 건너뛰기 → 상태 카드 → 하단 메뉴 4개 → 시점 3개 → 연기 토글 → 걷기 → 설정 패널 전체 → 비상정지 → 가로 화면
- 화면: 폰(390×844, 터치, 배율 2)과 PC(1440×900)
- 단계마다 스크린샷을 찍었습니다(`tests/out/ux/`, 저장소에는 올리지 않음).
- 단계마다 화면도 검사했습니다: 버튼 크기, 요소 겹침, 잘린 글자, 12px 미만 글자, 화면의 글자 양.
- **한계:** 이 환경은 SwiftShader라 부드러움, 프레임, 로딩 시간은 판정할 수 없습니다. 화면 등급도 LITE로만 봤습니다.

### U16 흐름 표현: 선 대 구름 질감 (사용자 제안, 2026-10-29, 결정 대기)
사용자 제안: 유적선 리본(선) 대신 구름 같은 질감이 더 효과적일 수 있음.
- 판단: 후류·박리 영역은 구름 질감이 난류를 더 직관적으로 보여 줍니다. 앞쪽 층류 구간은 선이 방향을 더 정확히 보여 줍니다. 실제 풍동 연기도 앞에서는 줄, 후류에서는 구름입니다.
- 주의: 이전 볼륨 연기는 연기 격자(11~24 cm)의 수치 확산 때문에 줄기가 판으로 합쳐지고 후류가 불투명한 안개가 되었습니다(CHANGELOG "연기 가독성"). 같은 방식으로 되돌리면 재발합니다.
- 구름의 잔결은 계산 결과가 아니라 시각 효과입니다. 계산이 담는 것은 수십 cm 규모까지라는 점을 표기해야 합니다.

| 안 | 방식 | 장점 | 위험 |
|---|---|---|---|
| A (추천) | 입자마다 노이즈 질감의 부드러운 연기 덩이를 붙임. 크기와 퍼짐은 솔버의 난류 강도로 정함 | 격자 확산 없음, 폰 부담 작음 | 입자가 적으면 듬성듬성 |
| B | 볼륨 레이마칭 + 절차적 노이즈 디테일 | 영화 같은 질감 | 폰 비용 큼, 안개 재발 위험 |
| C | 선 유지 + 후류 소용돌이 발광 강화 | 작업 최소 | 구름 느낌 약함 |

다음 단계: 사용자 지시 후 A안 시제품을 만들어 현재 화면과 전후 캡처로 비교합니다.
